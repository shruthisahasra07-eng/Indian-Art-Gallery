# KALAKRITI (कलाकृति)
### The National Digital Indian Art Gallery & Masterclass Learning Platform

A museum-grade digital platform and learning sanctuary dedicated to preserving, celebrating, and teaching **35 authentic traditional art forms of India**.

---

## 🌟 Key Features

### 1. 35 Authentic Indian Art Traditions (All Regions)
- **East**: Madhubani (Bihar), Pattachitra (Odisha/Bengal), Kalighat (Bengal), Manjusha (Bihar), Sohrai (Jharkhand), Khovar (Jharkhand), Alpana (Bengal).
- **West**: Warli (Maharashtra), Pichwai (Rajasthan), Phad (Rajasthan), Rogan Art (Gujarat), Pithora (Gujarat/MP), Mandana (Rajasthan), Rajput / Kishangarh (Rajasthan), Khavda Pottery (Gujarat).
- **South**: Tanjore (Tamil Nadu), Kalamkari (Andhra/Telangana), Cheriyal (Telangana), Kerala Mural (Kerala), Mysore Painting (Karnataka), Chittara (Karnataka), Lepakshi Frescoes (Andhra), Kalamezhuthu (Kerala).
- **North**: Mughal Miniature (Delhi/Agra), Sanjhi Stencil Art (Mathura, UP), Company Style (Pan-India).
- **Central**: Gond Tribal Art (Madhya Pradesh), Bhil Dot Art (Madhya Pradesh/Rajasthan).
- **Himalayan**: Kangra Miniature (Himachal Pradesh), Thangka (Sikkim/Ladakh), Aipan (Uttarakhand), Basohli (Jammu & Kashmir), Chamba Rumal (Himachal Pradesh).

### 2. Beginner-to-Masterclass Tutorials for Every Art Form

### 6. 🖌️ Authentic Progressive Painting Demonstration Engine
- **Eliminated "Playing with Shapes"**: Replaced primitive geometric canvas shapes with an authentic, hyper-realistic 6-phase painting process:

  - **Phase 6: 24K Gold Foil Embellishment & Netra Daan**: Gilded border shimmer, gold particles, and eye opening.
- **Dynamic Artisan Brush Cursor**: Features an animated wooden bamboo kalam handle, brass ferrule, natural hair bristles, and wet pigment droplet physically painting on the canvas.
- **Interactive Control Bar**: Instant Phase 1–6 stepper jump, 1x/2x/4x speed accelerator, and direct canvas transfer.

## 🚀 Instant Deployment Guide

This project is built with **zero external runtime dependencies** (Vanilla HTML5, CSS3, ES6+ JavaScript), meaning it runs with zero build steps, instant load times, and can be deployed to any static host in under 60 seconds:

### 1. Vercel
```bash
# Install Vercel CLI (if not installed)
npm i -g vercel

# Deploy directly from directory
vercel --prod
```

### 2. Netlify
Drag and drop the project folder directly onto [Netlify Drop](https://app.netlify.com/drop), or run:
```bash
npm i -g netlify-cli
netlify deploy --prod --dir=.
```

### 3. GitHub Pages
1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "Initial Kalakriti launch"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git push -u origin main
   ```
2. In GitHub repository settings -> **Pages** -> Source: Deploy from branch `main` / root.

### 4. Firebase Hosting
```bash
npm i -g firebase-tools
firebase login
firebase init hosting
firebase deploy
```
